14 Aug 2026
Phase 0 · Done

Private test chain

Forked current Ravencoin Core into an independent network. New magic (RUCK), ports 8867 / 8866, K addresses, burn addresses, genesis. Built a node on Ubuntu in WSL. Mined with KAWPOW. Sent RUCK. Issued TEST_RUCK. Rebranded what people see without changing consensus.

Exit check: a local node can mine, send, and issue an asset. Met.

What this is not: a public launch. The test wallet holds mined coins. Those coins do not become the public supply.

14–18 Aug 2026
Phase 1 · Now

Public record

This website, the white paper (v1.0), and this timeline. Honest status: private test, nothing to buy.

Exit check: anyone can open the site, read the paper, and see the same frozen parameters as doc/LAUNCH_SPEC.md.

late Aug – mid Sep 2026
Phase 2 · Next

A wallet people can actually use

Linux Qt did not appear on the Windows desktop. The current local page only shows balances.

  • A local wallet UI: receive address, send RUCK, assets
  • A desktop shortcut that starts the node and opens that UI
  • A simple local explorer (height, txid, K address)
  • Written miner notes for the one-node setup

Exit check: a person who is not us can receive, send, and issue an asset on the test node without using raw RPC.

Sep – Oct 2026, after Phase 2
Phase 3

Public launch day (height 0)

  • A published start time in UTC
  • A chain that begins at height 0 with no spendable premine
  • Tagged source and binaries (at least Linux; Windows if the wallet is ready)
  • This website and GitHub showing the same genesis hash
  • One honest public seed if we are willing to keep it up

Exit check: a stranger can download software, mine or receive a first coin, and verify genesis against this site.

Hard rule. If we skip the reset and call the test wallet the public coin, we have broken the white paper.

After Phase 3, if used
Phase 4 · If

Only if people actually show up

  • 2–3 seed nodes (small VPS, port 8867). Hostnames go into vSeeds.
  • A public explorer
  • GPU / stratum instructions that do not assume our living room
  • A published veterans donation address and a one-page report of how inflows will be shown

Exit check: a new peer can find the network without knowing our home IP.

Later, only with a reason
Phase 5 · If

Markets (optional)

There is no official DEX, CEX, or liquidity plan required to exist. If people want to trade RUCK, that can be a community pair or a pool someone funds with their own cash. The project will not pretend a market is part of consensus.

Exit check: none. Skip forever if there is no reason.

Not on the calendar

  • Masternodes, staking, an ICO date
  • A built-in veterans tax
  • “Listing on a major exchange by Q4”
  • A second coin, an NFT marketplace, or a mobile app before a working desktop wallet
