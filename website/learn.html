Field brief

How it works

This page is the kitchen-table version. The white paper is the full version. The spec is the stamped numbers.

The notebook

Imagine a notebook that many computers keep a copy of. Every minute or so, someone is allowed to add a page. That page is a block. It lists who sent what to whom. The whole stack of pages is the chain.

To add a page, a miner must solve a hard puzzle. Checking the answer is easy. Finding it takes a lot of graphics-card work. That puzzle is called KAWPOW (the same family Ravencoin uses). On average the network wants one new page per minute. If pages start coming too fast, the puzzle gets harder by itself.

In one sentence: new RUCK is created only when a miner wins the right to write the next page. The prize is 5,000 RUCK, until the first halving.

Halving, without a chart

Every 2,100,000 blocks — about four years if the clock stays near one minute — the prize is cut in half. The curve stops at 21 billion RUCK. That schedule is copied from the Bitcoin / Ravencoin idea: lots of coins early, then slower, then done. Nobody can print extra from a special key.

Your wallet is a key ring

A wallet does not “store coins on the app” the way a game stores gold. It stores keys. The chain stores the fact that those keys can spend certain outputs.

If you lose the keys, nobody can help you — not us, not a bank. If someone else gets the keys, they can spend the coins. Write the backup down. Do not screenshot it into a chat.

Why addresses start with K

A RuckCoin address looks like K… and is fairly long. Ravencoin addresses look like R…. We made them different on purpose so you do not send the wrong coin to the wrong book.

Never send Ravencoin (RVN) to a K address, or RuckCoin (RUCK) to an R address. The coins will not arrive. There is no undo button.

Assets are named things on the same book

RUCK is the native coin. An asset is a name you create, with a quantity you choose. Examples people actually use this design for:

  • a ticket to an event
  • a membership card that can be transferred
  • a unique item (only one exists)
  • an in-game thing that can leave the game

The first person to create a given name owns that name. Creating it burns a fixed amount of RUCK (500 for a normal name) so squatters cannot register every word for free. The burn goes to an address nobody can spend — including us.

The chain does not know if your asset is a concert ticket or a joke. The law in your country still applies. This is not a loophole.

What “fork of Ravencoin” means

We copied the Ravencoin software (which itself comes from Bitcoin) and started a new network. That is a code fork, not a split of their chain.

  • Ravencoin peers will not talk to RuckCoin peers. The handshake word is RUCK, not theirs.
  • RVN holders do not get an airdrop.
  • We kept the parts that already work: assets, one-minute blocks, GPU mining.
  • We changed the identity: name, ports, addresses, genesis, seeds.

Veterans — the honest version

We did not put a veterans tax on every block. We did not mint a foundation pile at the first block. Those tricks look generous and are usually a premine with better copy.

After the public start we will publish one donation address. Anyone can send to it. Anyone can watch it. If we later burn part of what that address receives, we will publish the transaction. If we do not, you will be able to say so.

What you should not do today

  • Do not buy “RUCK” from a stranger.
  • Do not treat the private test wallet as the public coin. It will be reset.
  • Do not announce this as a live network. It is one test node.

When Phase 3 is done, this page will say so, with a start time and a genesis hash you can check.
