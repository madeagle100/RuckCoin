FAQ

If an answer here disagrees with the white paper, the paper wins. If the paper disagrees with the running code after launch, the code wins.

Can I buy RUCK right now?

No. There is no sale, no ICO, and no official market. You can mine the test chain for practice. Those coins will be wiped. Anyone selling you RUCK for cash is not this project.

Is this Ravencoin?

No. We copied Ravencoin’s software and started a new network. Ravencoin coins (RVN) stay on Ravencoin. RuckCoin addresses start with K. Ravencoin addresses start with R. Do not mix them.

Is there a premine?

The public start will have none. Ops and listing coins are filled after height 0, in published locks. Test coins will not carry over. If we ever call the test wallet the public coin, we have broken the paper.

How do veterans actually get support?

One published address after launch. Optional donate in the official wallet (off unless you turn it on). Every spend gets a date, amount, category (housing, clothes, named shelter, etc.), and a transaction id. We do not publish a person’s name or story. Details: veterans page. There is no address to send to today.

When does it launch?

After a wallet people can actually use (Phase 2). Target window for a height-0 public start is September–October 2026 if that wallet is ready. See the timeline.

How are new coins created?

Mining only. About one block a minute. 5,000 RUCK per block until the first halving at 2.1 million blocks. The puzzle after genesis is KAWPOW (GPU).

What is an asset?

A name you create on the same chain, with a quantity you choose — a ticket, a membership, a unique item. Creating a normal name burns 500 RUCK so names stay scarce. The chain does not make your asset legal. The law still applies.

Do I need to put money in to launch?

No. Nodes, wallets, and mining do not require a DEX pool. Optional later, if people want a trading pair, someone would have to fund that with their own cash. Launch does not depend on it.

What are the locks, and who unlocks them?

Two published pots after official launch: ops (running the project) and listings (exchange deposits and pair inventory). No genesis pile. No block tax. Holders with the official wallet and a published minimum of RUCK vote to unlock a named amount. If the vote fails, nothing moves. Details: Open books.

Will you list on an exchange?

After official height-0 launch, yes — we will push for it. Mining creates coins. A listing is how people can trade those coins for other money. Without that, a mineable coin stays stuck on your computer. We will apply to centralized and decentralized exchanges and do the follow-up. We cannot make an exchange say yes, and we will not name a venue, a date, or a price. There is no listing today. Test coins will be wiped and are not money.

Where is the code?

github.com/madeagle100/RuckCoin. Open source, MIT license.

How do I get a wallet?

Same zip on every computer, from the wallet page. Windows: Open Wallet.bat. Linux/Mac: python3 ruck-wallet.py. You still need a node for your OS — that is on the Start page.

Which download is for my computer?

Start — pick Windows, Linux, or Mac. The wallet zip is shared. Only Linux has a ready node zip today (Ubuntu 24.04, 64-bit). Windows can run that Linux node inside WSL. Mac builds the node from source.

Does the site have to show a home IP address?

No. People use seed.ruckcoin.org. That name points at the test PC. The raw house number is not printed on the flyer. Official launch can move that name to a small server without changing the coin. RPC stays off the internet either way.

Can I run a node today?

Yes. Download the files on the Start page, put addnode=seed.ruckcoin.org:8867 in ruck.conf, and start your node. That seed is a home PC and will go down. This is a test. Official launch is still a fresh height 0.

Can someone else launch “RuckCoin” with their own genesis while we test?

They can copy the code. That is what open source means. A different genesis hash is a different coin — same as someone copying Bitcoin’s code and starting a new chain. It is not this project. Official RuckCoin is only the start time and genesis hash printed on this site and on github.com/madeagle100/RuckCoin. Until we publish that start, there is no official public chain. A clone that uses our test genesis still has our test coins in the builder wallet; those are not a public supply. We will reset at height 0.

Will you lock the veterans fund until the coin grows?

No. A lock until a price or a market cap would make help wait on a market. After launch the fund is for documented aid. We publish every spend. We do not publish a live address before launch, so there is nothing to lock today.

How do I report a bug?

Use the report box. Do not send keys or passwords. The page does not show a personal email address.

What if I send coins to the wrong address?

They are gone. There is no support desk that can reverse a blockchain payment. Check the first letter. K is RuckCoin. R is Ravencoin.
