Straight answers

FAQ

If an answer here disagrees with the white paper, the paper wins. If the paper disagrees with the running code after launch, the code wins.

Can I buy RUCK right now?

No. There is no sale, no ICO, and no official market. The public network is not open. Anyone offering you RUCK for cash today is not this project.

Is this Ravencoin?

No. We copied Ravencoin’s software and started a new network. Ravencoin coins (RVN) stay on Ravencoin. RuckCoin addresses start with K. Ravencoin addresses start with R. Do not mix them.

Is there a premine?

The public start will have none. A private test chain was used to prove mining and assets. Those test coins will not carry over. If we ever call that test wallet the public coin, we have broken the paper.

How do veterans actually get support?

One published address after launch. Optional donate in the official wallet (off unless you turn it on). Public list of outflows. No tax on every payment, and no lock until a price. Details: veterans page. There is no address to send to today.

When does it launch?

After a wallet people can actually use (Phase 2). Target window for a height-0 public start is September–October 2026 if that wallet is ready. See the timeline.

How are new coins created?

Mining only. About one block a minute. 5,000 RUCK per block until the first halving at 2.1 million blocks. The puzzle after genesis is KAWPOW (GPU).

What is an asset?

A name you create on the same chain, with a quantity you choose — a ticket, a membership, a unique item. Creating a normal name burns 500 RUCK so names stay scarce. The chain does not make your asset legal. The law still applies.

Do I need to put money in to launch?

No. Nodes, wallets, and mining do not require a DEX pool. Optional later, if people want a trading pair, someone would have to fund that with their own cash. Launch does not depend on it.

Will you list on a big exchange?

We will not promise that. Listings are other people’s decisions. They are not on the calendar.

Where is the code?

github.com/madeagle100/RuckCoin. Open source, MIT license.

How do I get a wallet?

Download it from the wallet page. Unzip, start your node, then open Open Wallet.bat. Your K address is on the first screen. You do not need to mine to use it.

Can I run a node today?

You can build the software from the public source. The public network is not open yet, so there is nothing useful to connect to. Wait for the published start.

Will you lock the veterans fund until the coin grows?

No. A lock until a price or a market cap would make help wait on a market. After launch the fund is for documented aid. We publish every spend. We do not publish a live address before launch, so there is nothing to lock today.

What if I send coins to the wrong address?

They are gone. There is no support desk that can reverse a blockchain payment. Check the first letter. K is RuckCoin. R is Ravencoin.
