Same zip · every computer

The wallet

This is the official window. It runs on your computer and talks only to a node on that same computer. The zip is the same for Windows, Linux, and Mac. The node file is not — that depends on your OS.

Windows

Windows

Unzip. Double-click Open Wallet.bat if a node is already running. Or Start RuckCoin.bat to try starting a node next to this folder (WSL + Linux node zip for now).

Download wallet

Linux

Linux

Start the node from the Linux node zip first. Then python3 ruck-wallet.py from this zip and open http://127.0.0.1:8870/

Download wallet

macOS

Mac

Build the node from source, then the same zip: python3 ruck-wallet.py. There is no Mac node download yet.
